# Banking Management System

A college database project built using Python, Flask, and MySQL.

## Features

- Dashboard displaying customer and account statistics
- Customer and account information
- MySQL database integration
- Database schema for banking operations
- Planned deposit, withdrawal, transfer, and loan management

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
